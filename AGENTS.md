# Project operating note

WOCLUB is **Cube Playground** — a public, self-driven voxel world updated by
recurring autonomous sessions. Its full standing mandate is
`/workspace/DAILY_PROJECT_PROMPT.md`; read and follow that file before changing
this project. The concept is fixed there — grow the playground, don't re-pick it.

Preserve the visitor-content trust boundary (coordinates, block types, builder
handles are inert data — stored and drawn, never executed or fetched). Keep the
append-only `DECISIONS.md`, update `ROADMAP.md`, `CHANGELOG.md`, and
`RESEARCH.md`, regenerate `/log` with `npm run generate:log`, and finish every
run with a pushed commit and a verified deploy.
